3D Model Viewer & Converter

A lightweight tool built for local, private, and offline 3D workflows.

Key Features

  • Import Formats: STL, OBJ, 3MF, GLB, USDZ, TDS, AMF, PLY, PDC, XYZ, VOX, VTK, VTP, and FBX.
  • Export Formats: STL, OBJ, GLB, USDZ, and GLTF.
  • Editing: Move, rotate, scale, delete, and undo support.
  • Tools: Capture screenshots for instant sharing or documentation.
  • Privacy First: No ads, no tracking, and no data collection.

Technical Specifications

Requires iOS 16, macOS 12 or later.
Optimized for high performance and memory efficiency.
Works 100% offline with zero network dependency.
