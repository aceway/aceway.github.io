Choose the conversion workflow you need

  • Single File: choose a model, select an output format, and convert. The result stays beside the preview with actions to share or locate the file. Supported windows show source and result side by side; compact windows let you switch between them.
  • Batch Files: select several models, choose one output format, review the save location, and convert. Each model produces its own output file.
  • Folder Scan: choose a folder, source-format filters, and whether to include subfolders. Choose the output format and start conversion. Output subfolders follow the source folder structure.

Preview helps confirm geometry. It is optional for batch and folder conversion; a preview failure does not by itself prevent an otherwise successful export.

Which formats are supported?

Import: STL (ASCII or binary, including the binary .stlb alias), OBJ, GLB/glTF, FBX, 3MF, USDA, USDC, and USDZ.

Export: STL, OBJ, GLB, FBX, 3MF, USDA, USDC, and USDZ.

Conversion is geometry only. Materials, textures, animation, skinning, cameras, and lights are not preserved. OBJ material files and texture companions are not loaded. Prefer self-contained GLB and packaged models; external companion resources are not automatically discovered.

This app converts existing mesh models. It does not generate 3D models from photos, repair meshes, recover CAD solids, or import STEP/IGES. There is no guaranteed maximum file size: available memory, geometry complexity, and source-file structure affect conversion.

Where are my converted files?

By default, files are saved in the app’s Documents/exported folder. Single-file and batch outputs use a flat folder; folder conversion preserves subfolders beneath a source-folder entry.

On iPhone and iPad, use Open in Files or Share. On Mac, use Open in Finder or Share; batch and folder preparation also let you select another output folder. Single-file conversion uses the app’s exported folder on every platform.

You can revisit successful files in Records → Exports. Removing an export-list entry does not delete its file. If a file has been moved or deleted outside the app, convert again to produce a new output.

Repeating a single-file conversion can replace its previous output. Batch and folder workflows can skip an unchanged source when a matching successful output is still present. Keep a separate copy if you want to retain an earlier version.

What is free, and what needs an in-app purchase?

All supported input formats are available without a format purchase. Single-file conversion to STL, OBJ, or GLB is free. Paid access depends on the output format and workflow, not the input format.

  • More Export Formats Lifetime: unlocks FBX, 3MF, USDA, USDC, and USDZ output.
  • Batch Conversion Lifetime: unlocks the Batch Files workflow.
  • Folder Convert & Mac Monitor: unlocks folder conversion on iPhone, iPad, and Mac, plus continuous monitoring on Mac.
  • Pro Weekly, Monthly, or Annual: unlocks all three feature groups while the subscription is active.

The three permanent purchases are separate. Advanced output formats in a batch or folder workflow require both the corresponding workflow purchase and More Export Formats, or an active Pro subscription. The app shows current localized prices before purchase.

How do I restore or manage purchases?

Open Unlock and choose Restore, using the Apple Account associated with the purchase. Connect to the App Store if products or purchases cannot be loaded. Pending or unverified purchases do not unlock features until Apple confirms them.

Subscriptions renew automatically unless canceled. Use Manage Subscriptions to view or cancel a subscription; see Apple’s cancellation instructions. Deleting the app does not cancel a subscription. Refund requests are handled by Apple.

If required access expires or is revoked, the app keeps completed outputs and pauses subsequent paid work. Valid permanent purchases continue to unlock their own feature groups. After restoring access, start the conversion or monitoring again when you are ready.

Purchases use Apple’s Standard End User License Agreement. Purchase availability and restoration depend on Apple’s store and account status.

How does automatic folder monitoring work?

On Mac, open Folder Scan, choose a source folder and conversion settings, enable automatic monitoring, then start monitoring. The app checks for eligible new or changed files while it is running. Use Stop Monitoring on the home screen to stop.

Monitoring must be started explicitly after launch. It is not a background service that continues after quitting the app; sleep or suspension can interrupt it. iPhone and iPad support folder conversion, but not continuous folder monitoring.

Keep the destination outside the monitored source tree. If access is lost, select the source or destination folder again. Files that are still downloading or being written may need to finish before they can be converted.

A file will not convert. What should I check?

  1. Confirm that the extension is supported and that the file contains mesh geometry. Renaming an unsupported file does not convert its contents.
  2. If the file is stored with a cloud provider, download it fully first. Select it again if it was moved or file access expired.
  3. Use a self-contained export from the source app. For glTF workflows, try GLB when the source depends on external resources.
  4. Check available storage and the error shown in Records. For a complex file, try a smaller export; you can turn off preview for batch and folder conversion.
  5. If an output format is locked, review the format and workflow purchases described above.

Why do size, orientation, or appearance differ?

The app uses a valid declared unit when available, otherwise the format default. STL and OBJ have no reliable unit declaration here and are treated as millimeters. Check the source application’s unit settings before export if the result appears too large or too small.

Materials and textures are omitted, so appearance may differ even when geometry converts. Preview up-axis, shading, and camera controls change only the display; they do not rotate or edit the exported model.

USD outputs use meters and declare Y-up without rotating source coordinates. Verify the output in your destination application when its axis or unit conventions differ.

Which devices can I use?

iPhone and iPad require iOS / iPadOS 26 or later. The Mac app requires macOS 26 or later and Apple silicon. This product does not include a visionOS version.

Conversion runs locally. Downloading cloud-backed inputs, App Store purchases, restoring access, opening web links, and sharing to online destinations may require a network connection.
