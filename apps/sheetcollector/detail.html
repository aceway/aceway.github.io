SheetCollector

Easily import tables from various files and images. Keep everything organized and export anytime. Generate polished PDF or JPEG documents with your own style.

DOMAIN INSIGHT

SheetCollector:xlsx ods...pdf

Transforming a physical paper into a flat digital image requires complex mathematics. The app uses the Vision framework to detect the four corners of a document in real-time, then applies a homographic transformation to rectify the perspective, making the scan look like it was flatbed-scanned.

CORE FEATURES

Import spreadsheet data from CSV, XLSX, ODS, TSV, and UTF-8 encoded JSON files.
Import table data from MySQL, MariaDB, PostgreSQL, and SQLite3 databases.
Import table data from PNG, HEIC, JPG, BMP, TIFF, and WebP images.
Use your device’s camera to scan and import spreadsheet data.
Add, modify, or clear data by row or column.
Swap any two rows or columns instantly.
Export filtered data as CSV, PDF, or JPEG by row or column.
Customize PDF/JPEG exports with A0-A5 sizes, portrait/landscape modes, and long-page JPEG formats.
Add logos and private statements for professional documents.
Set tiered protection for the exported PDF file, separately setting a read password and an edit password.

QUESTIONS

Where can SheetCollector import tables from?

From CSV, XLSX, ODS, TSV, and UTF-8 JSON files; from MySQL, MariaDB, PostgreSQL, and SQLite3 databases; from PNG, HEIC, JPG, BMP, TIFF, and WebP images; and from your device camera.

How does scanning a printed table work?

The app uses the Vision framework to detect the four corners of a document in real time, then applies a homographic transformation to correct the perspective so the scan looks flatbed-scanned.

What export formats and options are supported?

Filtered data can be exported by row or column as CSV, PDF, or JPEG, with A0–A5 sizes, portrait or landscape, and long-page JPEG output. Exports can carry your logo and a private statement.

Can I protect an exported PDF?

Yes. Exported PDFs support tiered protection, with a read password and an edit password set separately.
